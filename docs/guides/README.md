# Guides for people

the date its steps and limits were checked on the providers' own pages.

Guías paso a paso para usar y ayudar a Qbit Nutrition. Cada una tiene versión en inglés y en español, e indica la fecha en
que se comprobaron sus pasos y límites en las páginas de los propios proveedores.
